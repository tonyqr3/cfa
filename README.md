# CFA & Associates Website

A modern, responsive website for CFA & Associates, Chartered Accountants in Ghana.

## Run the website

You need Node.js 22 or newer.

```bash
npm install
npm run dev
```

Open the local address shown in your terminal.

## Main files to edit

- `app/page.tsx` — all homepage text and sections
- `app/globals.css` — colours, spacing, typography and responsive layout
- `app/layout.tsx` — page title, description and fonts
- `public/` — website images

## Useful commands

```bash
npm run dev      # start local development
npm run build    # create a production build
npm run lint     # check the source code
```

## Design system

- Deep navy: `#08253d`
- Mid navy: `#0e3552`
- Gold: `#c9a663`
- Warm cream: `#f4f0e7`
- Body text: `#13222e`

The layout is responsive and includes desktop and mobile navigation, services,
about, insights, contact and footer sections.
